# Lesson 02: Create and Drop Database 🏗️

## 🎯 Objective
Learn how to create and delete databases using SQL.

---

## 📖 Creating a Database

To create a new database, use the `CREATE DATABASE` command:

```sql
CREATE DATABASE database_name;
```
✅ Example
```sql
CREATE DATABASE company_db;
```

---

## 🗑️ Dropping a Database

To delete a database permanently, use the DROP DATABASE command:
```sql
DROP DATABASE database_name;
```
⚠️ Warning

This command will permanently delete the database and all its data.

✅ Example
```sql
DROP DATABASE company_db;
```

---

## 🧠 Key Notes
- Database names should be meaningful
- Avoid deleting databases unless necessary
- Always double-check before using DROP
