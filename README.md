# Learn SQL 🚀

A structured and beginner-friendly SQL learning journey designed to help you master database fundamentals, SQL commands, and real-world query writing step by step.

---

## 🎯 Purpose of This Repository
This repository is created to:
- Learn SQL from scratch in an organized way
- Understand database concepts clearly
- Practice SQL commands with real examples
- Build strong fundamentals for backend and data-related development

---

## 📚 What You Will Learn

- Database fundamentals
- SQL syntax and structure
- Data definition and manipulation
- Querying data efficiently
- Working with transactions and permissions

---

## 📂 Repository Structure

Each lesson is organized in a separate folder:
- lesson-01-introduction/
- lesson-02-...
- lesson-03-...


Every lesson contains:
- Explanation of the topic
- SQL commands
- Clean examples
- Practice section (in some lessons)

---

## 🚀 Goal

By the end of this repository, you will:
- Understand how databases work
- Write SQL queries confidently
- Be ready for SQL interviews and backend development basics

---

## 🛠️ How to Use This Repo

1. Start from `lesson-01-introduction`
2. Follow lessons in order
3. Read explanations carefully
4. Practice writing SQL queries yourself
5. Repeat and build consistency

---

## 📌 Notes

This is a learning-focused repository, so consistency matters more than speed. Practice is the key to mastering SQL.
